# Doom game assets

`websockets-doom.js` and `websockets-doom.wasm` are unmodified GPLv2 Chocolate Doom WebAssembly build artifacts from [doom-web](https://github.com/danborden1/doom-web) at commit `e0ba81004e27e7d66141925dfebb091a558e2fe8`. The corresponding engine source is [Saketh-Chandra/doom-wasm-pwa at a77edfd8bbc7](https://github.com/Saketh-Chandra/doom-wasm-pwa/tree/a77edfd8bbc7). The GPLv2 text is in `COPYING`.

`freedoom1.wad` is Freedoom Phase 1 version 0.13.0, distributed under the modified BSD license. Its license and contributor credits are in `FREEDOOM-COPYING.txt` and `FREEDOOM-CREDITS.txt`.

`doom1.wad` is id Software's unmodified Doom v1.9 shareware Episode 1 data (4,196,020 bytes; SHA-256 `1d7d43be501e67d927e415e0b8f3e29c3bf33075e859721816f652a526cac771`). It was extracted from [Debian's doom-wad-shareware 1.9.fixed-5 package](https://deb.debian.org/debian/pool/non-free/d/doom-wad-shareware/), which records its origin as the [idgames shareware archive](https://www.gamers.org/pub/idgames/idstuff/doom/doom19s.txt). The original license and John Carmack's redistribution clarification are in `DOOM-SHAREWARE-LICENSE.txt`. This shareware data is copyrighted by id Software and has different terms from Freedoom and the GPL engine.

`default.cfg` comes from the same `doom-web` commit. The surrounding `index.html`, `doom.css`, and `doom.js` are opiek95 integration code.
