# 88×31 web buttons

`arcade`, `emdash`, `pelican`, and `smile` GIFs and still PNGs come from [A90's 88×31 experiment](https://a90.com/experiments/88x31/), which invites visitors to take a button. Artwork by Cody Collier / A90. Each button in the site links back to its page in the source collection. The PNGs are used when a visitor prefers reduced motion.
